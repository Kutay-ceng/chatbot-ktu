# chatbot-ktu
Karadeniz Teknik Üniversitesi (KTÜ) Bilgisayar Mühendisliği bölümü için geliştirilen,
soru-cevap odaklı bir chatbot projesidir.

Bu proje, öğrencilerin bölümle ilgili sıkça sorulan sorulara hızlı ve doğru cevaplar
alabilmesini amaçlamaktadır.

## Proje Geliştiricileri
- Muhammet Doğukan Bingöl
- Kutay Keleş
- Ahmet Taha Dinç
- Onur Karaahmet
- Ataberk Güneş

## Projenin Amacı
- KTÜ Bilgisayar Mühendisliği öğrencileri için bilgilendirici bir chatbot geliştirmek,
- Bölüm, dersler, akademik kadro ve genel bilgiler hakkında otomatik cevaplar sunmak,
- NLP (Doğal Dil İşleme) tekniklerini uygulamalı olarak kullanmak.

## Kullanılan Teknolojiler
- Python
- NLP (Natural Language Processing)
- Git & GitHub

---

This project is a question–answer oriented chatbot developed for the
Computer Engineering Department of Karadeniz Technical University (KTU).

The aim of this project is to help students quickly and accurately find
answers to frequently asked questions about the department.

## Project Developers
- Muhammet Doğukan Bingöl  
- Kutay Keleş  
- Ahmet Taha Dinç  
- Onur Karaahmet  
- Ataberk Güneş  

## Project Aim
- To develop an informative chatbot for KTU Computer Engineering students,
- To provide automatic answers about the department, courses, academic staff,
  and general information,
- To apply Natural Language Processing (NLP) techniques in practice.

## Technologies Used
- Python
- NLP (Natural Language Processing)
- Git & GitHub
